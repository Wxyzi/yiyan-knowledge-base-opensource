# 记录一条可追溯的证据

笔记的价值不只是保存一句话，还在于让以后阅读的人能够理解判断从何而来。下面使用完全虚构的文本，不涉及真实用户或受试者。

## 从具体记录开始

假设材料 A 的第三段写着“这个工具可能缩短整理时间”。记录材料编号和段落位置，并保留理解这句话所需的上下文。公开笔记时，只使用有权公开的材料。

| 层次 | 记录内容 |
| --- | --- |
| 来源 | 虚构材料 A，第 3 段 |
| 观察 | 句子使用“可能”，而不是确定性承诺 |
| 解释 | 作者对效果有所保留；这是待验证的解释 |
| 限制 | 单个句子不能代表所有材料的表达方式 |

## 回到更多材料检验

查看其他语境中相似表达的用法，并寻找不符合初步解释的例子。若需要比较数量，必须说明材料范围、计数单位和分类规则。

## 与研究问题连接

回看[研究问题示例](/articles/sample-research-question?lang=zh)：这条证据能回答其中哪一部分？不能回答的部分应明确保留，而不是用推测补齐。

# Writing a Traceable Evidence Note

A useful note preserves not only a sentence but also how a judgment was reached. The text below is entirely fictional and contains no real user or participant data.

## Start with an identifiable record

Suppose paragraph 3 of document A states, “This tool may reduce preparation time.” Record the document identifier, location, and enough context to understand the sentence. Publish only material you are entitled to share.

| Layer | Record |
| --- | --- |
| Source | Fictional document A, paragraph 3 |
| Observation | The sentence uses “may” rather than a definite promise |
| Interpretation | The writer qualifies the claim; this interpretation needs checking |
| Limitation | A single sentence cannot represent every document |

## Check additional material

Inspect comparable expressions in other contexts and look for counterexamples. Quantitative comparisons require a defined collection, counting unit, and classification rules.

## Connect back to the research question

Revisit the [research question sample](/articles/sample-research-question?lang=en). Which part of the question can this evidence address? Leave unsupported parts open rather than filling them with speculation.
